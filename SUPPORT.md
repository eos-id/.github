# Support

Choose the appropriate channel:

- **Usage and implementation questions:** open a Discussion in the relevant repository when Discussions are enabled.
- **Reproducible defects:** search existing issues, then open an issue using the repository's bug report template.
- **Feature proposals:** describe the problem, affected actors, expected outcome, and constraints in a feature request.
- **Security concerns:** follow [SECURITY.md](SECURITY.md). Do not post vulnerabilities publicly.
- **Governance or cross-repository questions:** open an issue in this repository and identify the affected repositories and owners, if known.

Please provide reproducible context while removing secrets, personal data, and customer-identifying information. Response times are not guaranteed until maintainers publish a support commitment.
